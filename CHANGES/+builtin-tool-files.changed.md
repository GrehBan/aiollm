**Breaking:** for provider packages. `IFilesAdapter.to_download_method` (and `BaseFilesAdapter`'s) takes the whole `ProviderFile` instead of its id, so that a provider downloads a `ProducedFile` from its container or refuses it where it has none: a provider changes the parameter and reads `file.id`, with `container_of(file)` for the container. In the test kit, `BuiltinCase` takes `coded`, `coded_stream`, `produced` and `code_files` (a code execution that made a file, and the files a `CodeExecution` reads), and `FilesCase` takes `container_download` (the path of a container file's download, `None` for a provider without containers): a provider adds them to its cases.
