Built-in tools, the ones a provider runs itself, in the shared request and response: `WebSearch` and `CodeExecution` (with `UserLocation`), the two both providers have, and `ProviderTool` for a provider's own, all in the `tools=` list beside the functions (`request.tools` keeps the functions, `request.builtin_tools` has the rest). A response has `server_tool_calls` (`ServerToolCall`: `kind`, `status`, `queries`, `code`, `error`, the provider's items in `raw`; a failed tool is a call with `FAILED`, not an exception) and `citations` (`Citation`), a stream has `ServerToolCallEvent` for the start and the end of a call, and `CompletedEvent` carries the same two fields. `IncompleteReason.PAUSED` is a turn the provider paused. A provider takes them from its own release: the 0.15 provider packages send no built-in tool yet. For providers and tests: `check_builtin_tools` in `aiollm.adapters`, `BuiltinCase` for the shared scenarios (a `GenerationCase` without one skips them) and a web search and a code execution in the echo provider, with the new names in the extension API.
