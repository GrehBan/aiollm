Files of built-in tools: `GenerationResponse.files` and `CompletedEvent.files` list the files a built-in tool made (a chart the code drew) as `ProducedFile`s, a `ProviderFile` with its `filename`, the `container_id` of a code container and the `source_call_id` of the call that made it, as far as the provider tells them; `client.files.download(file)` streams one from wherever it lives, a container included. `CodeExecution(files=[...])` puts stored files into the sandbox for the code to read. A file of a container is reached only by `download`: `retrieve`, `delete`, a part's `file` and `CodeExecution.files` refuse it with `RequestValidationError`, as they refuse another provider's file. `aiollm.adapters.container_of(file)` tells an adapter which container holds a file.
